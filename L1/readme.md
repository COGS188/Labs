# L1

In this task, you will develop three AI agents which solve the classic Vacuum Cleaner Problem: the random agent, the reflex agent, and the model-based agent.

# Implement AI policies

In the `/src` directory, navigate to the agent.py file.

In the TrivialVacuumEnvironment class, there are four places to update the code (TODO: your code here). Use the function docstrings as a guide. 

The first function (execute_action) executes actions and tallies points.
The last three functions (random_agent, reflex_agent, model_based_agent) define the AI policies. 

After you finish, you can run the unit test to make sure that your implementation is correct.

# How to Run Unit Test

You can run the unit test via the following command on the `/L1` directory

```py
python -m unittest discover -s tests
```

If you see

```bash
(base) <your-username> L1 % python -m unittest discover -s tests
...........
----------------------------------------------------------------------
Ran 11 tests in 0.000s
```

this indicates that you have passed all the tests.
